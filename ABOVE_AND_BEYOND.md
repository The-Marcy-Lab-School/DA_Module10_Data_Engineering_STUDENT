# Above & Beyond

Optional. Do these **after** MVP is genuinely solid — a shaky MVP with
extra features isn't the goal. Pick 1-2, not all of them.

## A real Lakeflow (Delta Live Tables) declarative pipeline

Real, included in Databricks Free Edition (one active pipeline per
type) — a genuinely different, **declarative** programming model from
"run my script top to bottom." Rebuild your same real transformation as
a real Lakeflow pipeline and show it running for real.

## A second real transformation, a different Spark concept

Your MVP's aggregation is one real Spark pattern. Show a genuinely
different one against your same real dataset — a real join across two
real datasets, or a real window function (e.g. a real month-over-month
ranking) at real scale.

## Real deployment to one real free-tier cloud service

The base deliverable only requires a written explanation, not deploying
anything real. Go one step further: actually upload your real gold
layer's Parquet files to a real S3 (or Blob Storage / Cloud Storage)
free-tier bucket, and write up what was actually easy vs. actually
annoying about it — grounded in what you really did, not a
hypothetical.
